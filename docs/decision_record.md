# Decision Record Schema

Fields produced per applicant:
- pd: probability of default
- lgd: loss given default
- ead: exposure at default
- ecl: expected credit loss
- limit: chosen credit limit
- rate: chosen interest rate
- term: chosen term in months
- profit: expected profit of chosen offer
- fallback: which profile (credit / cashflow / behavior) scored the applicant
- explanation: top drivers + counterfactual
